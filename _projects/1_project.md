GreenPath is a web app that helps applicants understand and navigate the US green card process. It combines structured pathway guidance with AI features grounded in official sources.

Key features:

- **Pathway explorer** — answers a short questionnaire and maps you to likely eligibility categories (family, employment, EB-1 through EB-5).
- **Notice scanning** — upload a USCIS notice and OCR extracts dates and case details into an actionable timeline, with citations.
- **Visa Bulletin tracker** — select your category (F1-EB5) and priority date to see current movement, grounded in the live bulletin.
- **Multilingual support** — guidance and document explanations across languages.

Built with a static frontend deployed on Netlify and a Python backend calling the Anthropic API with strict JSON contracts for each AI feature.

Source: [github.com/wwhaiming/greenpath](https://github.com/wwhaiming/greenpath)
